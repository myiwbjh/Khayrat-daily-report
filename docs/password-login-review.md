# 邮箱和密码登录

日报系统默认显示邮箱和密码表单，使用 Supabase Auth 的 signInWithPassword，在当前浏览器建立会话。无需每次发送或点击邮件。SDK 继续保存、恢复和续期会话；密码不进入日报、日志、地址栏或应用本地存储。后端白名单、身份验证、RLS 和私有存储权限不变。

已有邮箱用户无需创建新用户。首次为已有账号设置密码：在已有登录会话的浏览器打开本次预览，点击“设置登录密码”，用户自己填写至少 12 位密码并确认。updateUser 仅更新当前已验证用户，保留 user ID 和数据归属。若没有任何有效会话，需要先使用一次备用邮箱验证，或在支持的账号管理流程中完成密码重置。Supabase 控制台密码、Vercel 密码不等于日报用户的密码。

取消和 Escape 会清空输入并使当前登录请求失效。晚到的成功响应不能向应用发布会话，且执行本地退出清除 SDK 会话。请求完成清理前不接受第二次登录，避免相互覆盖。失败使用统一错误，不显示上游信息。

Supabase–Vercel 平台集成解决项目配置和资源管理，并不能直接赋予日报应用用户身份。这次不调整平台集成、生产环境变量、Auth Provider 或数据库权限，不合并 PR。

验证：99 项单元测试通过，构建和语法检查通过；20 项本机浏览器回归通过，包含密码登录、刷新恢复、错误密码、输入清空，以及请求提交后取消/Escape 的晚到成功响应清除。Supabase 请求使用隔离的模拟服务，不代表真实密码登录和实际云端写入已验收。真实密码首次设置必须由用户完成，不通过聊天、PR 或仓库传递密码。
