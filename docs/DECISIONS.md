# 决策记录

## 2026-11-06 管理闭环与数据可信度
- 沿用现有 `risk_actions`、`equipment_shipments.payload`、`image_evidence.payload` 和 Crosswalk，不新增表。新推导风险在分派前只进入界面队列，禁止因读取页面自动创建无负责人 `open` 记录；`open/monitoring` 事项必须有负责人和承诺日期。批量分派逐项复用同一校验，并在 `history` 保留原承诺、前次承诺、状态和来源快照。
- 正式 WBS 实际值采用“可追溯且无歧义”门禁：周报一对一映射可直接采用；多 WBS 只接受人工 Crosswalk `allocation:<0..1>`、有备注、覆盖全部目标且比例合计 100%。否则保留周报实测供核对，但不拆分、不按基准量自动分摊，也不标为可决策。
- 计划月末与周报月中、最新实绩只覆盖部分 WBS、或任何 `basisIssues` 均属于混合口径，项目偏差不计算，状态显示“部分实测 · 待分解/暂定”。
- 30% 融资触发必须同时具有逐箱实际到场、合同/批次适用范围、验收/签收日期和签认依据；系统产物恒为待财务确认事项。批次里程碑、ETA、预计到场及推断到场均不能触发付款或应付确认。
- 照片去重分两级：SHA-256 完全一致且满足既有跨来源同日同车间安全范围才可自动合并；感知哈希相似只产生人工候选，任何专项修复或后台识别路径均不得据此删除对象。
- 安装条件批量操作只针对筛选后明确勾选的箱件和明确填写的条件，来源文件/记录必填；实际到场字段禁止批量操作。单箱人工控制继续承担例外覆盖，并记录字段级 `manual-confirmed` 来源及历史。
- 字段来源优先级为 `manual-confirmed > current-verified > original-source > unknown`。高优先级可覆盖低优先级；同级冲突不静默覆盖，进入 `pendingSourceConflicts` 并保留双方来源。
- 业主供电—调试依赖必须记录结构化承诺日期和证据，调试范围单独保存；缺任一项不能保存为持续跟踪。公开页继续只发布白名单字段，人工闭环、融资和依赖证据均不进入公开投影。
